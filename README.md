# Personal Portfolio

This repository contains the source code for my personal portfolio built with React, Vite, and TypeScript.

## Project Setup

To get started with this project, you'll need to have Node.js (v16 or later) installed on your machine. This project utilizes Vite as the build tool for a fast development experience.

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Aiza166/personal-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd personal-portfolio
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```

### Running the Development Server
To run the development server, use the command:
```bash
npm run dev
```
This will start the server on `http://localhost:3000` by default.

## Technologies Used
- **React**: A JavaScript library for building user interfaces.
- **Vite**: A modern build tool that provides a fast development environment.
- **TypeScript**: A typed superset of JavaScript that compiles to plain JavaScript.
- **CSS Modules**: For scoped styles in components.
